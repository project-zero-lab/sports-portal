# 🏅 Sports Portal

> Manage equipment, check the ground, score live matches and learn the rules for Kho-Kho, Volleyball, Badminton and Football.

**Live:** https://project-zero-lab.github.io/sports-portal/

**Built by:** Hiti Bisht · Project Zero × Claylab Education Foundation (Cohort 1)

## What it does
- Tracks equipment with quantity, condition and location
- Records ground inspections: surface, markings, safety status and notes
- Runs a live two-team scoreboard with a match timer and event timeline
- Saves a game journal for observations, fouls, strategy and reflections
- Includes a rules, equipment and pre-game checklist guide for four sports
- Exports data as JSON or CSV and restores it from a backup file

## How to use
1. Open the live link
2. In **Inventory & Ground**, add equipment and save a ground check
3. In **Live Match**, pick a sport, name the teams and tap **Start match**
4. Use **＋ / −** to update the score and **Add event** to log fouls and key moments
5. Tap **Finish & save result** to store the match
6. Write notes in **Game Journal** and read rules in **Game Guide**
7. In **Save & Resume**, download a backup before clearing your browser or switching devices
